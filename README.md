# 🎨 Delaunay Wallpaper Generator (Low Poly Art)

🌐 **English** | [Português](#-gerador-de-wallpapers-delaunay-low-poly-art)

A geometric art and wallpaper generator based on **Delaunay Triangulation**, featuring faceted 3D rendering, dynamic gradients, and instant export.

Built with **pure HTML5, CSS3, and JavaScript**, ready to run directly on **GitHub Pages** with no build step or installation required!

---

## ✨ Features

- **🎲 Random Button**: Generates a new pattern with unique colors, 3D lighting, and geometry on every click.
- **🖱️ Right-Click to Copy Image**: Since the art is exported directly into an `<img>` tag, you can **right-click anywhere on the screen and select "Copy image"** or "Save image as...".
- **📋 Copy Image Button**: A shortcut that copies the image straight to your operating system's clipboard.
- **💾 Download PNG Button**: Saves the `.png` file with a single click.
- **🖥️ Resolution Selection**:
  - Current Screen (Auto)
  - 1080p Full HD (1920x1080)
  - 2K QHD (2560x1440)
  - 4K Ultra HD (3840x2160)
  - Mobile / Story (1080x1920)
  - Square (1440x1440)
- **🎨 14+ Curated Palettes + Harmonic Algorithmic Generator**: Sunset, Cyberpunk, Nordic Glacier, Rainforest Emerald, Dark Obsidian, and more.
- **⌨️ Keyboard Shortcuts**:
  - `Space`: Generate a new random wallpaper
  - `C`: Copy image
  - `S`: Download PNG image
  - `H`: Hide / Show the control panel

## ✨ Funcionalidades

- **🎲 Botão Random**: Gera um novo padrão com cores, iluminação 3D e geometria únicas a cada clique.
- **🖱️ Copiar Imagem com o Botão Direito**: Como a arte é exportada diretamente em uma tag `<img>`, você pode clicar com o **botão direito em qualquer lugar da tela e selecionar "Copiar imagem"** ou "Salvar imagem como...".
- **📋 Botão Copiar Imagem**: Atalho que copia diretamente para a área de transferência do sistema operacional.
- **💾 Botão Baixar PNG**: Salva o arquivo `.png` com um clique.
- **🖥️ Seleção de Resolução**:
  - Tela Atual (Automático)
  - 1080p Full HD (1920x1080)
  - 2K QHD (2560x1440)
  - 4K Ultra HD (3840x2160)
  - Celular / Story (1080x1920)
  - Quadrado (1440x1440)
- **🎨 Mais de 14 Paletas Curadas + Gerador Algorítmico Harmônico**: Sunset, Cyberpunk, Nordic Glacier, Rainforest Emerald, Dark Obsidian, etc.
- **⌨️ Atalhos de Teclado**:
  - `Espaço`: Gerar novo wallpaper aleatório
  - `C`: Copiar imagem
  - `S`: Baixar imagem PNG
  - `H`: Ocultar / Mostrar painel de controles
